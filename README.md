# RESOLVEFARM

A professional agricultural e-commerce website for RESOLVEFARM, a Canadian farm specializing in fresh produce.

## Tech Stack
- HTML5
- CSS3 (Flexbox, Grid, Custom Properties)
- Vanilla JavaScript (ES6+)

## Project Structure
- `/pages`: HTML pages for different sections
- `/css`: Stylesheets (Base, Responsive, Animations)
- `/js`: Modular JavaScript files
- `/assets`: Images, icons, and logos

## Setup
Simply open `index.html` in your browser. No build tools are required for this phase.
